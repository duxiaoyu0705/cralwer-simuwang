# Simuwang 基金数据抓取

自动从[私募排排网数据中心](https://dc.simuwang.com/smph/a0ab1ac3)抓取中证500指数增强策略基金的"收益走势图"折线数据，输出实际百分比数值到 Excel。

## 快速开始

```bash
# 1. 安装依赖
pip install playwright pandas openpyxl
playwright install chromium

# 2. 配置账户（编辑 scrape_funds.py 顶部）
#    ACCOUNTS = [{"phone": "你的手机号", "password": "你的密码"}]

# 3. 运行
python3.10 scrape_funds.py
```

## 配置

编辑 `scrape_funds.py` 顶部常量：

```python
ACCOUNTS = [
    {"phone": "13800138000", "password": "password1"},
    {"phone": "13900139000", "password": "password2"},  # 可选：多账户轮换
]
ROTATE_EVERY = 50       # 每个账户抓取N条后自动轮换
FUND_COUNT = 0           # 0=全部（约165条），>0=指定数量
OUTPUT_FILE = "fund_chart_data.xlsx"
```

## 特性

- **全自动** — 登录、翻页、控件点击、数据解密全程自动化
- **实际数值** — 输出区间收益率百分比，非像素坐标
- **断点续传** — 中断后重跑自动跳过已完成的基金
- **多账户轮换** — 配置多个账户，降低单账户触发验证码的风险
- **安全验证等待** — 遇到"账户安全验证"弹窗自动暂停，等待手动输入后继续
- **失败重试** — API无响应时等待3分钟后自动重试（最多3次）

## 运行说明

- 脚本会自动打开 Chromium 浏览器窗口，**不要关闭**
- 每条约 45 秒处理 + 60 秒间隔 = ~105 秒
- 165 条全量预计约 5 小时
- `Ctrl+C` 可随时中断，已保存数据不会丢失
